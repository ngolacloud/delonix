# Delonix documentation UX/UI audit — 2026-10

Diagnosis of the site generated by `docs/gen.py` (published on GitHub Pages:
`https://ngolacloud.github.io/delonix`), against the supplied visual proposal and
the Docker/Podman/Kubernetes references. The framework (a single Python
generator, no CDN), the technical content, and the URLs are **preserved**.

Evidence captures (before/after) in `scratchpad/before/` and `scratchpad/after/`.

## Observed issues (with evidence and priority)

| # | Priority | Issue | Evidence | Status |
|---|---|---|---|---|
| 1 | P1 | **No global header.** Brand, search, language, and theme lived at the top of the *sidebar*, not in a top bar. | `sidebar()` (brand+toggles+search embedded); capture `before/index-light-1440` | **Fixed** (Phase 1) |
| 2 | P1 | **Sidebar permanently expanded, with no progressive disclosure.** The whole tree + *all* CLI commands and subcommands rendered at once. | `before/kinds-light-1440` (giant CLI list) | **Fixed** (`<details>` groups; CLI collapsed) |
| 3 | P1 | **Homepage opens with dense prose**, with no action path (no CTA, no 3 steps above the fold). | `INDEX_PT`; `before/index-light-1440` | **Fixed** (hero + CTA + 3 steps) |
| 4 | P2 | **Wasted margins/space.** Article column (860 px) centered in a wide column → empty space between sidebar↔article and article↔TOC. | `.layout 270\|1fr\|240 max 1600`; `main margin:auto` | **Fixed** (256\|1fr\|220 max 1400 grid; article on the left) |
| 5 | P2 | **Code blocks with no chrome; copy only on *hover*.** No terminal/file bar; YAML and `curl` with no copy. | `.copy-btn{opacity:0}`; `before/kinds` (YAML with no copy) | **Fixed** (Terminal/YAML bar + always-visible copy) |
| 6 | P2 | **Search not prominent** (inside the sidebar). Real indexing already existed. | `search-index.json` (775 records) | **Fixed** (moved to the header; indexing intact) |
| 7 | P3 | **Horizontal page scroll on mobile.** The "Why it's different" table and long inline `code` overflowed at 390 px. | Playwright measurement (`index 438>390`, `kinds 405>390`) | **Fixed** (tables with their own scroll; `overflow-wrap`) |

## Hypotheses to validate (next phases)

- **WCAG AA contrast** of secondary text (`--muted`), *syntax highlighting*, and
  navigation states, in both themes (§8). *To be measured with a tool.*
- **Very long TOC** on large pages (e.g. `kinds` lists ~25 anchors) —
  evaluate *scrollspy*/grouping.
- **200% zoom and deep anchors** opened directly (§14).
- **i18n parity** of the new header/top-nav text (ensured via `bi()`).
- **File name** on the kinds' YAML blocks (currently a generic "YAML" label;
  emit `data-filename` from `examples/<group>/<kind>.yaml`).

## Strengths preserved (do not touch without reason)

- Real Ctrl/Cmd+K search, indexed, with keyboard support and a *focus-trap*.
- Light/dark themes with semantic *tokens* + anti-FOUC (`THEME_INIT_JS`) +
  `prefers-color-scheme` *fallback*.
- PT/EN i18n via `bi()`/language spans; `contract_gate()` prevents binary↔docs
  drift; own *highlight* with no CDN; copy with a legacy *fallback*.
- Consistent orange identity (`--accent #e8590c`).

## Phased plan

- **Phase 1 — Global layout (DONE and validated).** Header, grid/spacing,
  collapsible sidebar, code chrome, action-oriented homepage. Validated
  with Playwright (no overflow across 5 pages × 4 widths; Ctrl+K; mobile drawer;
  copy) and light/dark/mobile captures.
- **Phase 2 — Pages by type.** Parameter tables, typed *callouts*,
  file name on YAML, *breadcrumbs* + previous/next, tuning for
  each type (kind, lab, CLI, concept).
- **Phase 3 — Accessibility + tests.** AA contrast, visible focus, 200% zoom,
  Playwright suite at 390/768/1440/1920 × light/dark (§14).
- **Phase 4 — Diagrams and metadata.** Architecture diagrams with identity
  (§11) and the examples' validation status (§10/§13).
